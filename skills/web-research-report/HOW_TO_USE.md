# web-research-report の使い方

## 概要

自然言語で指定したテーマを Web で調査し、出典付きの資料ファイルを作る単一フローの skill です。既定では読みやすい HTML を作成してプレビューします。Markdown を指定した場合は OKF v0.1 の基本形に沿った `.md` を作成します。

## 起動トリガー

- 「Web で調べて資料にして」
- 「調査レポートを HTML で作って」
- 「出典付きでまとめて」
- 「このテーマを OKF Markdown の資料にして」

## 出力形式の指定

形式は依頼文の中で指定します。

- 指定なし: HTML
- 「Markdown で」と指定: OKF v0.1 の基本形に沿った Markdown
- 「HTML と Markdown の両方」と指定: 両形式

HTML は単一ファイルで保存され、利用できる場合はローカルプレビューが開きます。Markdown は `type: Research Report`、`title`、`description`、`tags`、`timestamp` を含む YAML frontmatter を持ち、対象に正規 URI がある場合は `resources` も含めます。本文の引用番号は末尾の `# Citations` と対応します。図を含める場合は HTML、Markdown とも Mermaid.js 形式になります。

## 指定できる内容

- 調査テーマ
- 想定読者
- 資料の目的
- 対象期間
- 分量
- 出力形式
- 出力先

未指定の項目は依頼内容から推定され、必要な前提は資料内に明記されます。

## 使用例

```text
国内中小企業における生成 AI 活用の現状を Web で調べ、経営者向けの短い資料にして。
```

```text
2025 年以降のパスキー普及状況を調査し、エンジニア向けに Markdown でまとめて。
```

```text
再生可能エネルギーの導入推移を調べ、HTML と Markdown の両方で資料を作って。推移が分かりやすければ Mermaid の図を入れて。
```

## 常に行われること

- Web 検索と情報源本文の確認
- 冒頭への「エグゼクティブサマリー」の配置
- 重要な事実への引用参照の付与
- HTML では末尾への出所一覧の掲載
- Markdown では OKF frontmatter と、引用番号に対応する末尾の `# Citations` の付与

Web 検索、出所、Mermaid 形式の制約は省略できません。これらと矛盾する依頼では、調査済み資料を作ったように見せず停止します。
