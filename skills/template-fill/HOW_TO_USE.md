# template-fill の使い方

## 概要

外部で管理している Markdown テンプレートを受け取り、回答欄の空いた見出し・ラベル・チェックリスト・表セルを上から順に 1 問ずつ質問して、回答を書き込んだ Markdown ファイルを作る単一フローの skill です。サブコマンドは持たず、位置引数 1 つとフラグだけを取ります。

テンプレートは skill に同梱せず、実行のたびに渡します。日報・週報・議事録・報告書など、テンプレートを skill と切り離して git などで管理しながら運用する用途を想定しています。テンプレート自体は変更されません。

追加のランタイムや認証は不要で、ファイルを読み書きできるホストならどこでも動きます。

## 起動トリガー

- 「templates/daily.md で日報を書きたい」
- 「このテンプレートを埋めて」
- 「週報のひな形から作って」

## 位置引数

| 引数 | 説明 |
|---|---|
| `<template>` | テンプレートのパス。`.md` / `.markdown` のみ対応 |

## フラグ一覧

| フラグ | 値 | default | 説明 |
|---|---|---|---|
| `--output` | パス | `<テンプレート名>-<YYYY-MM-DD>.md` | 出力先。既定名が既に存在すれば `-2` `-3` と連番を付けます |

`--output=path` のような `=` 区切りも受け付けます。

## 排他・依存ルール

- `.md` / `.markdown` 以外のテンプレートを渡すと `exit 64`
- `--output` に既存ファイルを指定すると `exit 64` (上書きはしません)
- テンプレートが存在しない・読めない場合は `exit 66`

## テンプレートの書き方

特別な記法はありません。回答欄が空いている箇所が、そのまま上から順に質問になります。

```markdown
# 日報

- 日付:
- 氏名:

## 今日やったこと
<!-- 箇条書きで -->

## 明日やること

## 困っていること

## 作業区分
- [ ] 開発
- [ ] レビュー
- [x] 会議

| | 所感 |
|---|---|
| 午前 | |
| 午後 | |
```

| 質問になる箇所 | 質問文 | 書き込み方 |
|---|---|---|
| 値が空のラベル (`- 日付:`) | `日付` | ラベルの後ろに書きます |
| 本文が無い見出し (`## 今日やったこと`) | `今日やったこと` | 見出しの下に書きます |
| 見出し・ラベル直下のチェックリスト | `作業区分` | 選んだ行を `[x]` にします |
| 空の表セル | `午前 の所感` | セルに書きます。改行は `<br>` になります |

- 質問文はテンプレートの文字列そのままです。言い換えや前置きは付きません
- 見出しやラベルの直下の HTML コメントは、質問の補足として表示されます。回答を書いた箇所ではコメントが消えます
- テンプレートで既に `[x]` の選択肢は `(選択済み)` として示されます
- 下位の見出しだけを持つ見出しや、すでに本文がある見出しは質問になりません
- 回答は音声入力も想定して、打ち間違い・変換ミス・フィラー (`えー` / `あのー` 等)・言い直しを整えてから書き込まれます。要約や言い換えはしません。整えた箇所は最後の確認一覧に `方が痛い → 肩が痛い` の形で示され、元に戻すこともできます
- 複数行の回答は、各行が `- ` の箇条書きになります (すでにリスト記号がある行はそのまま)。Markdown で改行が 1 段落につながって表示されるのを防ぐためです

## 対話の流れ

1. いきなり 1 問目から始まります。質問は `[3/7] 今日やったこと` の形で 1 問ずつ出ます
2. 各質問には、回答のほか「スキップ」「戻る」「中止」と返せます
   - スキップした箇所はテンプレートのまま残ります
   - チェックリストには番号でも選択肢の文字列でも答えられ、選択肢に無い回答は行として追加されます
3. 全問答えると回答の一覧が出ます。了承すると書き出され、特定の質問だけ直すこともできます

## Word / Google Docs で使いたい場合

この skill は Markdown だけを扱います。完成した Markdown は、Google Docs の Markdown 取り込みや pandoc などで変換してください。

## 使用例

```bash
# 既定の出力先 (作業ディレクトリの daily-<日付>.md) に書き出す
templates/daily.md で日報を書きたい

# 出力先を指定する
templates/weekly.md を埋めて --output reports/weekly-2026-09-24.md
```
