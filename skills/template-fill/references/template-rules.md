# 質問の見つけ方と回答の書き込み方

テンプレートに特別な記法は無い。回答欄が空いている箇所を、そのまま質問として上から順に読む。

## 質問になる箇所

| 形 | 例 | 質問文 | 種類 |
|---|---|---|---|
| 値が空のラベル | `- 日付:` / `氏名:` | ラベルの文字列 (`日付`) | 自由記述 |
| 本文が無い見出し | `## 今日やったこと` の直後が同じか上位の見出し、または末尾 | 見出しの文字列 | 自由記述 |
| 見出し・ラベル直下のチェックリスト | `## 作業区分` の下に `- [ ] 開発` / `- [ ] レビュー` | 見出し・ラベルの文字列 | 複数選択 |
| 空の表セル | 見出し行が `課題`、行の先頭セルが `9/24` で、そのセルが空 | `9/24 の課題` のように行と列の見出しをつなぐ | 自由記述 |

- ラベルは、行末 (リスト記号の後ろを含む) が `:` または `：` で終わり、後ろに値が無い行
- 見出しの直下 (次の見出しまで) の中身で扱いを決める
  - 何も無い、または HTML コメントだけ: 自由記述の質問にする
  - チェックリストだけ (HTML コメントは含んでよい): 複数選択の質問にする
  - 下位の見出しだけ: 章立てなので質問にしない
  - それ以外の本文がある: すでに埋まっているので質問にしない
- 見出し・ラベルの直下にある HTML コメント (`<!-- ... -->`) は、質問の補足としてそのまま添える
- 同じ階層で連続する `- [ ]` / `- [x]` の行を 1 つのチェックリストとみなす。選択肢は各行の `[ ]` / `[x]` を除いた文字列
- 表の見出し行と先頭列のセルは、空でも質問にしない
- コードブロックの中は質問にしない

## 回答の整え方

回答は音声入力の場合もあるため、書き込む前に次の範囲で整える。意味・語調・情報量は変えない。

- 打ち間違い・変換ミスを直す。文脈から正しい語が 1 つに決まるものだけを対象にする (例: 質問が所感で `方が痛い` → `肩が痛い`)
- フィラー (`えー` / `あのー` / `えっと` / `まあ` / `なんか` 等) と、言い直しの前半を取り除く (例: `明日は、えーと、G社の、じゃなくてH社の対応` → `明日はH社の対応`)
- 音声入力で抜けた句読点を補う
- 固有名詞・社名・製品名・数値は、明らかな誤りでない限り触らない
- 要約・言い換え・敬体への変換・内容の補足はしない
- 直すべきか判断が付かない箇所は、そのまま残して確認時に示す

## 回答の書き込み

変えてよいのは、上の整え方と次に定める行の区切り方だけである。

複数行の回答で、リスト記号 (`- ` / `* ` / `+ ` / `1. ` 等) を持たない行は、各行を `- ` の箇条書きにする。Markdown では単純な改行が表示時に 1 段落へつながってしまうためである。空行は捨てる。すでにリスト記号を持つ行はそのまま使う。1 行だけの回答は箇条書きにしない。

- 値が空のラベル: 区切り記号の後ろに空白 1 つを挟んで書く。複数行の回答は、ラベルがリスト項目なら 2 文字下げた子の箇条書きとして、それ以外はラベルの次の行から箇条書きとして書き、ラベルの後ろには何も書かない
- 本文が無い見出し: 見出しの後ろに空行を 1 つ挟んで回答を書き、次の見出しとの間にも空行を 1 つ置く
- チェックリスト: 選ばれた行を `[x]`、選ばれなかった行を `[ ]` にする。行の順序と文言は変えない。選択肢に無い回答は、そのリストの末尾に `- [x] <回答>` として足す
- 空の表セル: 複数行の回答は `<br>` でつなぐ。回答中の `|` は `\|` にする
- 補足として添えた HTML コメントは、回答を書いた箇所では削除する。スキップした箇所では残す
- スキップした質問の箇所は、テンプレートのまま残す
- 質問以外の文字・空行・見出しレベル・リスト記号は変えない
